# Model Appendix — Fields and Verified Behaviours

Agreed in the November 2026 cross-team exchange (consensus D-H04): the workflow body stays model-agnostic; model-specific knowledge lives in an appendix table, one row per model actually used, each row dated and sourced. Old rows are never deleted, only marked expired. Facts below were verified against production records during the exchange; re-verify before relying on prices.

## Row fields

Model / version · use · reference-image limits · known filter behaviour · likeness distribution (with its calibration baseline) · unit price · suitable shot types · known failures · last verified date · source project.

## Verified behaviours (as of 2026-11-16 exchange records)

- **Grok Imagine Video 1.5 (xAI direct)**: 720p priced at US$0.14/sec + US$0.01 per input image (pilot bill-checked: 13 images, 4 sec = US$0.69). Built-in image generation is natively 1280×720; 9 reference images at once rejected, 4 or fewer in practice; reference images above 5, and 3+ real-person photos, trip filters more easily. Built-in video reaches 1080p only from pure text or a first frame alone; adding end/intermediate frames or references caps at 720p. Single-person likeness is strong; 3+ people in frame does not hold likeness.
- **Kling v3.0 Pro**: first/last frame, 720p ≈ US$0.112/sec; needs an identity negative prompt.
- **HeyGen video-1**: first frame OR up to 9 reference images, never both at once.
- **gpt-image (OpenRouter, "sunburst" route)**: won face-to-face comparisons on group shots in one production; 188 images averaged ≈ US$0.103/image.
- **Google Gemini 2.5 Flash Image**: cartoonises a real child's face; banned for face-critical shots of that production. Gemini 3.1 Flash Image was the keyframe workhorse (≈ US$0.077/image), Gemini 3 Pro Image for hero close-ups (≈ US$0.155/image).
- **Google Veo 3.1 Lite**: 720p silent generation ≈ US$0.03/sec, upscaled to 1080p in post for that production.

## Standing rules

- Thresholds are calibrated per pipeline from the project's own baselines (leave-one-out, reference ceiling, sheet-cell scores); absolute numbers in any record are one pipeline's example, never a universal gate.
- Before scoring faces in a frame, assign each detected face an identity (or "non-cast"); cartoon or stylised co-stars otherwise corrupt real actors' scores.
- A model row without a date and a source project is a rumour; treat it as unverified.
